When building EstateHub as a capstone project,
I wanted to step away from basic CRUD applications and build a system that mirrored enterprise-level relational complexity.

## The Architecture: Mapping 18 Tables
The backbone of the application is a deeply normalized MySQL database.
Handling user authentication, role-based access, property listings, and nested membership tiers required strict adherence to normalization principles to prevent data anomalies.
